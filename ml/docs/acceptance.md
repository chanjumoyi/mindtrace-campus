## OUHD-L 全量验收

- 2,403 条记录、37,508,288 个原始点，匹配规划基线。
- train/val/test：1,911/239/253 条，248/31/32 名书写者，writer_id 集合互斥。
- 258 个重复时间戳文件，聚合 2,398 个同刻同状态点；保留 76 个同刻状态转换边界，dt=0，速度无效。
- 无隔离异常；全量处理前后逐文件 SHA-256 相同。
- 训练集坐标范围与有效通道标准化独立拟合；可逆映射保留。设备物理单位仍未校准，不能声称毫米尺度或压力物理可比。
- 28 维统计特征全部有限，保留缺失掩码和 200/500/1000ms 停顿敏感性；6 个重复时间戳样例图留本地，已人工抽查轨迹、速度和压力图。
- 提供 2 秒不插值时间窗、原始索引区间、时间范围和独立 padding/measurement/augmentation 掩码；正式窗口选择仍属于后续步骤。
- 在仓库根目录与仓库外目录各完成一次全量运行，清单、全部统计特征和训练集归一化参数逐项一致；每个官方集合各保存一个真实窗口，并用 `allow_pickle=False` 重新加载全部字段。最终完整运行 status=passed，CPU affinity `0xffff0000`；每次运行独立目录，只有完整通过的运行可作为后续训练输入。

八项合成测试覆盖浏览器动态压力判据、真实 CSV 通道选择、只读哈希、缺文件、路径越界、参与者跨集合、同刻转换、零 dt、压力缺失、倒序拒绝、单位与几何、仅训练拟合、逆变换、窗口来源和 padding。保留大规模重复分组合成回归用例。

## 已验证的独立环境

- Python **3.10.20**，独立 `ml/.venv`，未复用后端环境。
- PyTorch **2.6.0+cu124**、CUDA runtime **12.4**、NumPy **1.26.4**；验证后锁定全部 22 个包版本于 `requirements.txt`，依赖兼容性检查通过。
- GPU：RTX 4060 Laptop，8,188 MiB，驱动 551.76；CPU/CUDA 均完成前向、反向、实际检查点文件保存及恢复，输出数值一致。
- seed=42、2 层双向 GRU、每方向 hidden=64、dropout=.2、batch=32、256 点、五通道，5 次前向/反向：CPU 约 **102.17 窗/秒**（4 线程），CUDA 约 **727.54 窗/秒**，峰值 allocated 显存 **158,326,272 字节**（约 151 MiB）。包含首次运行开销，仅为合成环境冒烟，不代表完整正式训练吞吐量或模型验收。
- CUDA wheel 来源为 PyTorch 官方 cu124 索引，完整 SHA-256 为 `7cc45c5b39d74875cfafe908b7f55c544147cc16b01e795feb2fe766583efe78`，分段续传后整包校验匹配；未跳过完整性检查。
- 默认 CPU 调度下，Python 3.10.6 和 3.10.20 均出现过长读取任务的访问异常；独立于 NumPy 的最小流式读取也复现异常，因此未把问题简单归因于某个依赖版本。切换至维护版本 3.10.20/NumPy 1.26.4，使用平坦数值缓冲与批量归约；该机器的数据准备命令显式记录进程 CPU affinity `0xffff0000`。仅该进程受影响，不修改系统设置，也不据此诊断硬件故障。旧环境保存在忽略目录 `ml/local/`。
