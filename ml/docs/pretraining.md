# OUHD-L 正式自监督预训练验收

本任务实现 training-flow.md 步骤 4，沿用步骤 3 的已验收 v3 冻结输入。仅训练 OUHD-L 轨迹编码器，不训练 WHO-5/DASS 预测头，不据重建指标声称心理预测有效。

## 固定协议

- 数据：官方 train/val/test，按 writer_id 隔离；训练 1,911 条记录、248 名书写者，验证 239 条、31 名书写者。来源哈希与步骤 2 的受控 inventory 逐条一致才读取，处理后再次检查源哈希。
- 输入：`ouhd-input-v3` / `event-windows-v3`，125 Hz、2 秒窗口/步长、至少 500 ms 尾窗。保留笔状态边界、缺失掩码、原始跨度和插值映射，不跨长空隙插值。训练 32,642 窗、验证 3,892 窗；窗口数不是独立参与者数。
- 标准化：沿用已验收窗口研究中只用全部训练记录拟合的坐标和所选采样率通道统计，不从验证/测试重新拟合。
- 模型：2 层 BiGRU、每方向 hidden=64、双向 128 维、dropout=0.2；16 个显式输入（5 观测、5 有效性、5 遮盖标志、1 笔画边界），重建 4 个连续通道，池化排除 padding。
- 遮盖：约 15% 连续片段，不跨笔画边界；只在被遮盖且真实有效、非 padding 的 dx/dy/dt/pressure 上计算 Huber。验证遮盖种子固定为 1042，测试固定为 2042，训练 seed=42 且逐轮更换遮盖与顺序。
- 优化：AdamW lr=0.001、weight_decay=0.01、batch=32、梯度累积=1、梯度范数上限=1；最多 50 epoch，验证 Huber 连续 7 轮无严格改善早停，不以测试集调整参数。空目标批次跳过，整轮无目标拒绝训练。
- 指标：总体损失按有效遮盖目标数量汇总，另列每通道 Huber、MAE、RMSE。指标单位为训练集标准化后的通道单位，不是毫米或原始压力单位；没有目标的通道记 null，不伪造为零误差。

## 产物与恢复

私有目录 `ml/experiments/pretraining/ouhd-formal-v1/` 保存完整参数、来源/实现/清单指纹、训练与验证缓存及划分索引、原始跨度/插值映射、标准化、运行环境、优化器、随机状态、每轮历史和峰值显存。

`last.pt` 与 `best.pt` 原子保存，`encoder.pt` 导出最佳编码器及完整输入契约。每个 epoch 的遮盖和打乱由 epoch 派生种子，dropout 由已保存更新游标派生种子。中断后从上一完整 epoch 冷恢复，未完成 epoch 重跑；恢复前核验来源、实现、配置、环境和缓存，不兼容拒绝。恢复不改变原始轨迹。

训练完成先写 `frozen.json`，然后在读取任何测试测量前落盘 `test-started.json`，对最佳冻结模型进行一次固定遮盖的独立评价。测试开始后发生中断会拒绝自动重评；已完成结果保持不变。`test-metrics.json` 记录实际被评价编码器的 SHA256，测试后再次确认编码器文件未变。

完整运行 50 epoch，达到预登记轮数上限，未触发连续 7 轮无改善早停。最佳模型来自第 45 轮，验证 masked Huber **0.06272172**；第 50 轮验证为 0.06374694，因此导出第 45 轮权重。导出编码器与最佳完整模型的 encoder 逐参数完全一致。

## 预算与图检查

50 轮训练及逐轮验证累计 **5,219.59 秒（86.99 分钟，约 1.45 GPU·小时）**，平均每轮 104.39 秒；按每轮训练窗数除以包含验证的轮次耗时计算，约 312.69 训练窗/秒。数据准备、源文件哈希核验、测试和检查另计。运行期间另做过一次小型 CUDA 恢复回归，耗时已包含在对应轮次墙钟统计内。

峰值 allocated 显存 **145.29 MiB**，系统工具观察到 GPU 总显存占用约 766 MiB；两者口径不同。batch=32、梯度累积=1 全程未调整，无 OOM。最终 `training-history.png` 已查看：训练和固定遮盖验证曲线总体下降，后期存在正常波动，显存曲线稳定，无损失发散或持续显存增长。图只留在忽略目录。

此次测量替代 OUHD-L 单种子预训练原先 2–5 小时的粗估，但不外推到 EMOTHAW 或 MindTrace。原总预算 10–20 GPU·小时与分项 12–25 小时的差异仍需在后续真实运行中修订；本次不勾选整个预算跟踪任务 8.1，也不宣称已覆盖内层调参、校准、消融和多种子开销。

任务 4.1–4.5 已完成；下游监督、WHO-5 迁移和个人预测验收不在本次范围内。单种子、一次固定遮盖的轨迹重建结果不证明跨域收益，更不代表能预测 WHO-5。
