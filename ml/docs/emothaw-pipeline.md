## 实现范围

- 只读 `configs/data.json` 指定的唯一 EMOTHAW 镜像根，在其中只扫描 `extracted/DataEmothaw/`；不读取、拼接其他下载或解压 ZIP，不移动/覆盖任何源文件。路径解析拒绝逃逸 canonical root。
- 标签只从 `DASS_scores.xls` 的 `Feuil1` 读取，明确不拼接 `Feuil2/Feuil3`。复合键为 `Directory + File Number user`，不能用 `Suject`、文件名编号或 Excel 行序替代。重复键、缺标签、非数值/非有限分数和不符合 I-DASS-42 原值范围的记录拒绝静默适配。
- Excel 中 depression/anxiety/stress 的原值原样传递，不乘 2、不除 2、不分级。原研究 I-DASS-42 与镜像计分历史是两个独立状态，格式/范围相容不证明镜像计分正确，也不构成正式训练许可。分类始终关闭。
- SVC 保留七列原始数组、声明/实际点数、缺失压力掩码、重复时间戳及源单位状态；真实零压力与缺失压力分别保留，不自动排序倒序轨迹。当前没有核实时间单位及物理坐标/压力映射，因此不伪造 epoch ms、不换算毫米或 dt_seconds、不复用 OUHD-L 的 0–4095 压力量程。通用 SVC 列约定参考 [BDALab 的格式说明](https://github.com/BDALab/handwriting-sample)，这不是 EMOTHAW 来源单位已核实的证据。
- 按目录参与者、session、任务分组，只选唯一无后缀 canonical 任务候选；同内容复制件不变成新样本，不同内容修正版保留并要求复核。无唯一 canonical 版本、文件名身份冲突、跨任务/参与者内容重复、声明点数不符、倒序、缺任务、多 session 和来源备注分别记录；参与者出现需复核问题时不得进入正式监督队列。
- 监督管线组件仅用合成数据测试：外层 5 折、内层 3 折以参与者分组，重复窗口不改变参与者身份，内层不含外层测试者；窗口先聚合到任务，再任务等权聚合到参与者，缺任务或未复核的多 session 拒绝聚合。
- 同结构两层 BiGRU 的从零、冻结编码器、局部微调三种模式均通过合成前向/反向和优化一步测试。冻结模式关闭编码器 dropout；局部微调只放开第二层，三个 DASS 维度使用独立连续输出头，无 softmax。正式迁移还须单独冻结来源、预处理和预算方案，不能据本组件测试声称真实迁移已完成。
