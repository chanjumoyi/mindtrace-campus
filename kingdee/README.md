# 苍穹平台交付区

该目录只存放可导出、可复现、可审计的苍穹资产及其说明。

```text
kingdee/
├─ lowcode/         # 领域模型、表单、流程、报表、服务模型清单/导出物
├─ kwc/             # KWC组件源码、构建配置、注册说明
├─ java-plugins/    # 苍穹Java插件与平台适配器
├─ agents/          # Agent定义、任务流、工具注册、平台导出物
├─ deployment/      # 安装包、初始化、升级和回滚说明
└─ evidence/        # 平台配置与运行轨迹截图索引
```

环境未就绪时先在对应目录维护设计清单，禁止凭猜测写死SDK版本。环境到位后记录：平台版本、KWC版本、JDK/SDK、模型、租户权限、插件打包方式和安装包格式。
