# 产品说明

状态：已按立项报告对齐
最后更新：2026-10-11

## 产品定位

“心迹AI”是面向大学生的心理健康智能交互与研究平台。项目通过日常对话、电子手账、情绪记录和笔迹书写行为，探索文本与行为特征的融合分析，并提供冥想、瑜伽和心理健康科普等自助支持内容。

平台定位为心理健康教育、日常支持和自我觉察工具。AI 输出属于辅助信息，不构成医学诊断，也不能作为危机处置、人格判断或学校管理决定的唯一依据。

## 项目范围

- AI 对话陪伴与非诊断性情绪支持。
- 电子手账、日常情绪和压力记录，以及纵向趋势展示。
- 基于 Canvas 的笔迹轨迹采集、行为特征提取和个人基线比较。
- 文本与笔迹特征的多模态情绪识别研究。
- 冥想与瑜伽跟练、每周心理健康科普和可解释推荐。
- 房树人绘画与心理沙盘的结构化采集、可观察元素描述和探索性提问。
- 用户调研、模型评估、可用性测试和效果评估材料。

## 不在当前范围

- 金蝶 AI 苍穹、KWC 或 Java 插件集成。
- 辅导员、管理员等多角色业务工作台。
- 咨询预约、审批、回访和校园行政处置流程。
- 自动心理诊断、自动危机判定或未经人工复核的高风险决策。
- 未经伦理审批和知情同意的真实学生敏感数据采集。
