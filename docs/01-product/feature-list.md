# MVP 功能清单

状态：已按立项报告对齐
最后更新：2026-10-11

## P0 平台与安全底座

- 用户注册、登录、退出和本人数据隔离。
- 知情同意、隐私说明、授权撤回、数据导出与删除。
- 结构化日志、请求标识、错误处理、数据库迁移和备份恢复。
- 高风险表达的安全提示、求助路径和人工复核边界。

## P1 核心功能

- AI 对话陪伴：支持多轮上下文、免责声明、超时降级和调用审计。
- 电子手账：新增、查看、编辑、删除和分页。
- 情绪记录：心情、压力、睡眠和备注记录，以及 7/30 日趋势。
- 笔迹采集：坐标、时间、停顿、速度，以及设备支持时的压力和倾角。
- 笔迹反馈：客观行为特征、数据质量、置信度、局限和个人历史比较。
- 自助内容：冥想、瑜伽、心理科普及完成记录。

## P2 研究功能

- 文本与笔迹特征的统一表征和多模态情绪识别。
- 房树人绘制或上传、结构化问卷、元素提取和探索性提问。
- 沙盘元素摆放、保存、结构化观察和回看。
- 个性化内容推荐，并允许用户关闭和查看推荐依据。
- 用户需求调研、模型离线评估、可用性测试和效果评估。

## 交付成果

- 一套可运行的 Web 平台。
- 系统设计说明书、用户测试分析报告和情绪识别模型评估报告。
- 项目研究报告、总结报告、演示视频、演示网站和结项材料。
