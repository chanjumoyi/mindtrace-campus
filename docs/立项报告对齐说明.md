# 立项报告对齐说明

## 1. 整理依据

本仓库以根目录《心迹AI——大学生心理健康智能交互平台立项报告》为唯一产品与技术范围基线。立项报告明确：

- 前端使用 Vue 3 构建 Web 网站；
- 后端使用 Python 与 FastAPI；
- 数据库使用 MySQL；
- AI 引擎使用 DeepSeek 或兼容大语言模型 API，并保留本地特征提取；
- 核心功能包括 AI 对话、电子手账、笔迹采集、多模态情绪辅助分析、冥想/瑜伽、心理科普、房树人和沙盘；
- 敏感心理数据采用最小化采集、本地处理和加密存储等保护措施。

## 2. 保留并迁移

| 原内容 | 新位置 | 原因 |
|---|---|---|
| 笔迹特征提取、基线预测、安全解释 | `backend/app/services/handwriting/` | 与笔迹采集和本地特征算法直接对应 |
| 指针坐标归一化 | `frontend/src/features/handwriting/` | 可用于 Vue Canvas 采集组件 |
| 沙盘 SVG 元素 | `frontend/src/assets/sandplay/` | 可直接用于交互式沙盘 |
| Prompt、工作流、安全用例、工具 Schema | `research/ai/` | 支撑 AI 辅助分析研究与评测 |
| 公开笔迹知识与研究脚本 | `research/handwriting/`、`research/knowledge/` | 保留可复现实验能力 |
| 分析 JSON Schema | `backend/app/contracts/` | 作为 API 和模型输出边界 |

## 3. 删除

- Java/Spring Boot 与第二套 Java 领域工程：与 FastAPI 技术路线冲突，且形成重复后端。
- 金蝶苍穹/KWC/Java 插件资产：来自后续竞赛适配方案，不属于本立项报告。
- PostgreSQL、Flyway 与旧 Docker 编排：数据库选型与立项报告不一致。
- 静态 HTML/JS 前端、Mock Agent 和独立笔迹 HTTP 服务：由 Vue 3 与统一 FastAPI 服务取代。
- IDE 配置、空壳目录、乱码交付文件、失效模板和损坏的嵌套 gitlink：不属于可运行产品或有效研究资产。
- 仓库内重复立项报告：根目录已保留正式 DOCX/PDF，代码仓库不再维护副本。

## 4. 分阶段范围

当前先保证“对话—记录—自助支持”的核心链路可运行。笔迹、房树人与沙盘作为探索性模块保留算法、素材、契约和入口，待完成伦理方案、样本设计和专业审核后逐步接入。任何探索模块都不得输出诊断结论。
