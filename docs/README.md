## 规范优先级

[系统架构说明](./02-architecture/README.md) 是开发实施的规范性基线，已经通过 [ADR-0001](./07-collaboration/decisions/0001-modular-monolith.md) 固化。新增模块、接口、数据表、后台任务或外部依赖前，必须先确认符合架构说明；涉及数据库、认证、模块所有权或部署单元的变更必须新增 ADR。

## 范围基线

- 技术栈：Vue 3、FastAPI、MySQL、DeepSeek 或兼容 LLM API、Canvas API。
- 核心功能：AI 对话陪伴、电子手账、情绪记录、笔迹行为分析、冥想与瑜伽、心理科普。
- 研究功能：文本与笔迹多模态情绪识别、房树人和心理沙盘的 AI 辅助观察。
- 研究工作：用户调研、模型离线评估、可用性测试，以及在伦理审批和知情同意前提下开展效果评估。
- 安全定位：平台只提供心理健康教育、日常支持和辅助观察，不提供医学诊断，不替代心理咨询或紧急服务。

## 已移出范围

- 金蝶 AI 苍穹、KWC 和苍穹业务对象适配。
- Java 或 Spring Boot 第二套后端。
- 辅导员工作台、管理员后台、咨询预约审核和回访任务。
- 与立项报告无关的企业协同、审批流和生产平台集成。

## 维护原则

1. 接口、字段或流程变化时，同步更新代码和文档。
2. 关键方案记录在 `07-collaboration/decisions/`。
3. 不提交真实身份、联系方式、心理记录、量表结果、笔迹、对话或密钥。
4. 在伦理审批、知情同意和专业审核完成前，不采集真实参与者敏感数据。
5. 对研究性分析明确展示证据、不确定性、适用范围和局限。
