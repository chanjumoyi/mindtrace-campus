# 系统设计说明书编写提纲

本文件是最终PDF的持续维护入口。每个章节应附“设计依据、具体方案、苍穹落点、验证证据”，不要只写概念。

1. 文档信息：版本、作者、评审人、变更记录。
2. 项目背景：政策、校园痛点、目标、范围、术语。
3. 需求分析：角色、用户故事、功能/非功能需求、验收标准。
4. 总体设计：业务闭环、系统上下文、逻辑/部署架构、技术选型。
5. 苍穹低代码设计：领域模型、表单、流程、报表、服务模型、权限。
6. 数据设计：ER图、表/字段字典、索引、分级、留存、模拟数据。
7. Agent设计：角色、Prompt版本、工作流、状态、工具、失败回退、评测。
8. 知识库：来源、审核、切分、元数据、索引、更新和下架。
9. 接口：OpenAPI、鉴权、幂等、错误码、限流、审计。
10. KWC设计：页面信息架构、组件、状态、交互、响应式和无障碍。
11. 安全伦理：知情同意、最小权限、危机SOP、提示注入、人工接管。
12. 部署运维：环境基线、配置、安装、初始化、升级、回滚、日志监控。
13. 测试：策略、用例、结果、缺陷、AI评测和安装验证。
14. 附录：模型清单、接口清单、截图索引、第三方资料与许可证。

## 必备图表

- 系统上下文图、总体架构图、部署图。
- 学生普通关爱与高风险处置泳道图。
- 核心ER图、关爱工单状态机。
- Agent编排图、工具调用序列图、RAG入库流程。
- 角色权限矩阵、环境/配置矩阵、接口清单。
