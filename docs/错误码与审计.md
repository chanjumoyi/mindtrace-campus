# 错误码与审计

| 错误码 | HTTP | 说明 |
|---|---:|---|
| INVALID_ARGUMENT | 400 | 参数或格式错误 |
| UNAUTHORIZED | 401 | 未登录、令牌失效或凭证错误 |
| FORBIDDEN | 403 | 权限不足 |
| NOT_FOUND | 404 | 资源不存在或不可见 |
| CONFLICT | 409 | 数据或并发冲突 |
| IDEMPOTENCY_CONFLICT | 409 | 同幂等键对应不同请求 |
| INVALID_STATE_TRANSITION | 409 | 非法任务状态切换 |
| FILE_TYPE_NOT_ALLOWED | 415 | 文件类型不在白名单 |
| FILE_TOO_LARGE | 413 | 文件超过限制 |
| RATE_LIMITED | 429 | AI 调用频率过高 |
| AGENT_UNAVAILABLE | 502 | Agent 重试后仍不可用 |
| AGENT_TIMEOUT | 504 | Agent 超时 |
| INTERNAL_ERROR | 500 | 未分类内部错误 |

每个 JSON 响应包含 `requestId`，并回写 `X-Request-Id` 响应头。审计日志记录操作者、动作、资源、结果、requestId 和时间；不记录密码、明文令牌、完整 Prompt、心理正文或文件内容。
