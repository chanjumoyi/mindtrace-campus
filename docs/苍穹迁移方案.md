## 三、JDK 版本兼容处理

### 3.1 差异

```
本地: JDK 17 (pom.xml: <maven.compiler.target>17</maven.compiler.target>)
cosmic: JDK 1.8 (gradle.properties: systemProp.jdk.version=1.8)
```

### 3.2 需修改的 Java 17 语法

| Java 17 特性 | 本地使用位置 | Java 8 等价写法 |
|-------------|-------------|----------------|
| `record` 类 | `SandplayLayoutGenerator.ElementTemplate` | 改为普通 `final class` + 构造器 + getter |
| `switch` 表达式 (`->`) | 多处 switch | 改为传统 `case:` + `break` |
| `var` 类型推断 | 部分方法 | 改为显式类型声明 |
| `text blocks` (`"""..."""`) | ContentFilterService | 改为 `String` 拼接或单行 |
| `List.of()` | 测试类 | 改为 `Arrays.asList()` |
| `.stream().toList()` | 部分方法 | 改为 `.collect(Collectors.toList())` |

### 3.3 编译方法

```bash
# 1. 更新 pom.xml 为 Java 8
# 2. 修复所有 Java 17 语法
# 3. 编译
cd local/java-domain
mvn clean package -Dmaven.compiler.source=8 -Dmaven.compiler.target=8

# 4. 拷贝 jar 到 cosmic
cp target/mindline-java-domain-1.0.0.jar ../cosmic/code/lib/
```

**不需要放 cosmic/code/lib/ 的另一种方式**：直接把源码放到 cosmic 工程中，用 Gradle 统一编译。推荐用源码方式，避免 jar 版本不一致问题。

## 四、Agent 平台配置清单

**在苍穹 Agent 平台 Web UI 中人工操作以下步骤：**

### 4.1 创建沙盘分析 Agent

```

1. Agent 名称: sandplay-analysis-agent

3. 绑定模型: 基座模型（DeepSeek/豆包/通义千问，按平台可用）
4. 关联工具: save_sandbox_record / get_rag_context
5. 关联知识库: sandplay-methodology
6. 输出 Schema: 粘贴 agent-output.schema.json 中的 sandplaySpecific 部分
```

### 4.2 创建房树人分析 Agent

```
1. Agent 名称: htp-analysis-agent
2. System Prompt: 粘贴 ai/prompts/htp-analysis-agent-v1.md
3. 关联工具: save_htp_record / get_rag_context / multimodal_describe_image
4. 关联知识库: htp-methodology
```

```
1. save_sandbox_record
```

### 5.2 插件框架代码

```java
package kdec.apple.cloud.app.plugin.other;

import kd.bos.form.IFormView;
import kd.bos.gptas.api.embedctrl.EmbeddedControlService;
import kd.bos.gptas.ctrl.dto.user.AgentParameter;
import kd.bos.gptas.ctrl.dto.ShowStyle;

/**
 * 心迹AI - AI嵌入式控件插件
 * 沙盘/笔迹页面通用，负责唤起苍穹嵌入式智能体对话面板
 */
public class EmbeddedAgentPlugin extends AbstractFormPlugin {

    @Override
    public void customEvent(CustomEventArgs args) {
        String method = args.getMethodName();

        switch (method) {
            case "openAgent":
                // 1. 读取页面上下文（沙盘元素 or 笔迹轨迹）
                String pageContext = buildPageContext();

                // 2. 配置智能体参数
                AgentParameter agentParam = new AgentParameter();
                agentParam.setAgents(getAgentList());  // 沙盘/笔迹智能体
                // mountingMethod: floatAboveTheContainer / embeddedToTheContainer / smallPopupWindow

                // 3. 打开控件
                ShowStyle style = buildShowStyle();
                EmbeddedControlService.show(getFormView(), agentParam, style);

                // 4. 注入页面上下文
                EmbeddedControlService.sendUserChat(
                    chatSessionId, skillId, "当前页面数据：" + pageContext
                );
                break;

            case "chat":
                EmbeddedControlService.chat(
                    args.getParams().get("chatSessionId"),
                    args.getParams().get("skillId"),
                    args.getParams().get("userInput"),
                    Map.of("pageContext", pageContext)  // 传递当前页面数据
                );
                break;

            case "stopStream":
                EmbeddedControlService.stop(
                    args.getParams().get("chatSessionId"),
                    args.getParams().get("taskId"),
                    args.getParams().get("flowId")
                );
                break;
        }
    }

    // 根据当前页面类型构建上下文
    private String buildPageContext() {
        // 沙盘页面: 读取元素数量/类别/描述
        // 笔迹页面: 读取笔划数/速度/停顿
        return "";
    }
}
```

## 七、逐步骤迁移操作

### 阶段 1: 环境准备

```
1. 确保 COSMIC_HOME=D:/kingdee/cosmic804 存在
2. gradle.properties 中 cosmic_home 正确
3. 在 IntelliJ IDEA 中 Import cosmic 为 Gradle 项目
4. 执行 gradle build 验证基础工程可编译
```

### 阶段 2: Java 代码迁移

```
1. 把本地 Java 源码复制到 cosmic 对应包目录（按 2.1 映射表）
2. 修改包名: com.mindline.* → kdec.apple.cloud.app.*
3. 修复 JDK 17 → 1.8 语法兼容问题（按 3.2 表格）
4. 在 cloud-app/build.gradle 的 dependencies 中添加依赖
5. gradle build → 验证编译通过
```

### 阶段 3: 本地调试

```
1. 运行 DebugApplication.main()
2. 确认 cosmic 服务启动在 http://127.0.0.1:8881/ierp
3. 调用 SandplayAnalysisService → 验证返回 JSON
```

### 阶段 4: AI 资产导入

```
1. Agent 平台注册智能体（粘贴 Prompt）
2. Agent 平台注册工具（粘贴 JSON Schema）
3. Agent 平台导入知识库（上传 md 文件）
4. Agent 平台配置任务流
```

### 阶段 5: 嵌入式控件联调

```
1. 表单设计器拖入 ai-embedding-ctrl
2. 绑定 EmbeddedAgentPlugin
3. 页面点击 AI 按钮 → 弹窗出现
4. 发送消息 → Agent 回复 → 验证上下文包含页面数据
```
