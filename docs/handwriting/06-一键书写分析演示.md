# 笔迹一键书写分析演示

## 当前闭环

```text
浏览器数位笔/Pencil书写
  -> 内存生成统一轨迹 JSON
  -> Python 特征提取
  -> 小样本岭回归原型（低置信度）
  -> Qwen 辅助说明（失败时安全降级 Mock）
  -> 同页展示结果、依据与限制
```

普通用户默认进入“直接分析模式”，系统生成匿名代号，不要求填写压力、心情或睡眠状态。团队继续采集训练标签时，可手动切换到“研究采集模式”。研究标签不参与本次输入推理，只用于后续离线训练。

## 启动

先生成或更新本机模型：

```powershell
python scripts\build_handwriting_dataset.py
python scripts\train_handwriting_baseline.py
```

模型默认从以下忽略目录加载，不会提交到 Git：

```text
data/handwriting-private/models/handwriting_ridge_v0.1.json
```

在配置了 Qwen 环境变量的同一个 PowerShell 中启动：

```powershell
python local\ai-lab\handwriting\service\server.py --port 8091
```

电脑打开：

```text
http://127.0.0.1:8091/collector/
```

同一局域网的平板打开：

```text
http://电脑局域网IP:8091/collector/
```

移动端只需要访问 8091 端口。若无法访问，应为 8091 创建限定为专用网络的 Windows 防火墙入站规则，不要关闭整个防火墙。

## 验收标识

- `qwen / SUCCESS`：Qwen 实际调用成功。
- `mock / MOCK`：主动使用本地 Mock。
- `mock / DEGRADED`：尝试调用 Qwen 失败后安全降级。
- `EXPERIMENTAL / LOW`：小样本工程拟合，仅用于技术链路演示。
- `UNAVAILABLE / NONE`：未加载拟合模型，系统仍会输出客观特征。

当前模型仅有少量参与者数据。页面必须保留“不得用于心理评估、诊断或个体决策”的提示，不得宣传为心理状态识别准确率。
