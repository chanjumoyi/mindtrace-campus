# 《笔迹心理学》候选特征证据矩阵

用途：把书中的描述转化为“可验证的候选研究问题”，而不是直接生成心理诊断标签。

## 使用规则

1. 每条记录必须注明版本和页码。
2. `book_claim`只做短摘要，不整页复制。
3. 必须给出可由代码复现的`operational_definition`。
4. 如果华为平板无法直接采集，对应字段标记为“不可测”。
5. 未找到独立实证研究支持前，只能标记为“探索性特征”。
6. 涉及人格、疾病、危险性的确定性解释默认不采用。

## 使用决定取值

- `采用`：定义清楚、设备可测、有相对充分证据，仅用于辅助观察。
- `探索`：可以进入实验，但不能成为报告中的确定性结论。
- `弃用`：不可测、定义无法复现、证据不足或伦理风险过高。
