# 笔迹采集与数据集起步方案

## 当前目标

第一阶段只证明三件事：华为平板能够稳定采集Huawei Pencil轨迹；数据可以回放和验证；同一接口能够支持后续特征提取与模型训练。

暂不输出心理结论，不把书中的笔迹解释直接当成训练标签。

## 首版任务

### 固定文本抄写

统一文本：

> 今天的努力，正在成为明天的底气。

作用：控制文字内容和大致笔画复杂度，便于比较同一参与者不同时间的书写变化。

### 60秒自由书写

统一题目：

> 今天让我印象最深的一件事。

作用：观察自然书写节奏，并收集与当日情境相关的用户自述。

## 数据集阶段

### D0：设备验证集

- 参与者：仅项目成员本人。
- 数量：每人固定抄写5次、自由书写3次。
- 目的：验证设备、浏览器、Schema、回放和数据质量。
- 禁止用途：不能用于训练心理状态分类器。

### D1：个人纵向试验集

- 参与者：仍以项目成员本人为主。
- 周期：连续7—14天，每天固定时间采集。
- 同步记录：压力、心情、睡眠和情境备注。
- 目的：验证同一人的速度、停顿、压力等特征是否具有稳定基线。

### D2：研究训练集

只有在完成知情同意、隐私方案、数据用途说明和必要的学校伦理/指导教师审核后，才考虑邀请其他参与者。训练集标签优先来自当次自评或经过审核的量表，不来自“某个字形必然代表某种心理”的主观推断。

## 《笔迹心理学》PDF的使用方式

该书可以帮助整理候选观察维度，但不能直接把书中每条解释当作事实标签。建立证据矩阵：

| 字段 | 说明 |
|---|---|
| feature_id | 特征编号 |
| feature_name | 特征名称，例如平均压力、停顿比例 |
| operational_definition | 可由程序复现的计算定义 |
| book_title/version | 书名与版本 |
| page | PDF页码/印刷页码 |
| book_claim | 书中原始观点的摘要，不大段复制 |
| measurable_on_device | 华为平板是否能采集 |
| external_evidence | 是否有独立研究支持 |
| use_decision | 采用、仅研究、弃用 |
| risk_note | 文化差异、主观性、诊断化风险 |

建议把PDF放在个人本地资料目录，不要直接提交到公开Git仓库，除非确认版权许可。仓库中只提交你们自行整理的短摘要、页码索引和证据矩阵。

## 数据管理规则

- 使用随机参与者代号，不使用姓名、学号、手机号。
- 原始轨迹只读保存，清洗结果另存。
- JSON与PNG使用相同会话ID关联。
- 每批数据记录数据集版本、设备型号、系统版本和浏览器版本。
- 不将自评压力标签描述为医学诊断标签。
- 不在团队群聊中散发原始私人书写内容。
