# 离线研究区

`research/` 只用于公开数据适配、离线特征、实验、评估和经过审核的 AI 研究资产。线上 API 不得导入这里的训练脚本、数据文件或实验配置。

## 当前状态

旧版华为平板导入脚本、旧 1—5 分标签基线、笔迹学 PDF/RAG 和对应测试已经移除。它们与新的统一数位板、PHQ-4/PSS-4、即时状态标签和公开数据适配器方案不兼容。

在[笔迹数据集与数位板采集规范](../docs/03-data/handwriting-collection-and-dataset-spec.md)中的统一轨迹 Schema 2.0 冻结前，不创建临时数据转换脚本。

## 目标结构

```text
research/
├─ datasets/
│  ├─ adapters/        # 每个公开数据集一个读取适配器
│  ├─ schemas/         # 统一中间格式
│  ├─ validation/      # 公共质量检查
│  └─ registry/        # 不含私密信息的数据源登记模板
├─ features/           # 公共离线特征构建
├─ experiments/        # 版本化实验配置
├─ evaluations/        # 指标、误差分析和安全评测
├─ ai/                 # Prompt、工作流、工具契约和模拟评测集
└─ artifacts/          # 模型与中间产物，必须被 Git 忽略
```

## 数据规则

- 下载的公开数据集和真人数据优先存放在仓库之外的受控目录；
- `research/private/` 仅作本地兼容位置，必须保持 Git 忽略；
- Git 只保存代码、Schema、许可记录模板、合成样例和不含个人信息的实验配置；
- 原始数据只读，标准化数据和派生特征写入新位置；
- 外部数据和真人数据不混用标签，训练、验证和测试按参与者隔离；
- 新增依赖时创建独立、锁定版本的研究依赖文件，不把大型机器学习依赖加入 API 运行环境。
