# 离线研究区

机器学习代码、数据目录、配置和实验输出统一进入 [`ml/`](../ml/README.md)。`research/` 保留现有 Prompt、工作流、知识库、工具契约、模拟评测、沙盘字典和合成样例，不再建立第二套训练流水线。线上 API 不得导入离线训练脚本。

## 当前状态

旧版华为平板导入脚本、旧 1—5 分标签基线、笔迹学 PDF/RAG 和对应测试已经移除。它们与新的统一数位板、PHQ-4/PSS-4、即时状态标签和公开数据适配器方案不兼容。

本次按照训练方案第 4.1 节建立 `ml/` 目录。数据适配和训练尚未实现，当前采集协议与标签不变。

## 保留结构

```text
research/
├─ ai/                 # Prompt、工作流、工具契约和模拟评测集
└─ data/               # 沙盘字典及合成样例
```

## 数据规则

- 下载的公开数据集和真人数据优先存放在仓库之外的受控目录；
- 训练数据存入被 Git 忽略的 `ml/data/`；`research/private/` 等旧目录继续忽略，已有历史数据核查后再迁移；
- Git 只保存代码、Schema、许可记录模板、合成样例和不含个人信息的实验配置；
- 原始数据只读，标准化数据和派生特征写入新位置；
- 外部数据和真人数据不混用标签，训练、验证和测试按参与者隔离；
- 训练依赖在 `ml/requirements.txt` 单独维护，首次环境验证后锁定版本，不加入 API 运行环境。
