# 华为平板笔迹采集器

这是心迹AI笔迹模块的第一阶段原型。它使用浏览器Pointer Events采集轨迹，不依赖苍穹环境，也不会自动上传数据。

## 启动

在PC上进入本目录后启动静态服务器：

```powershell
python -m http.server 8080 --bind 0.0.0.0
```

PC浏览器访问：

```text
http://127.0.0.1:8080
```

华为平板和PC连接同一Wi-Fi后，在PC运行 `ipconfig` 找到无线局域网IPv4地址，在平板浏览器访问：

```text
http://<PC的IPv4地址>:8080
```

如果平板无法访问，先检查Windows防火墙是否允许该端口。不要为了测试关闭整个防火墙；只对当前私有网络和指定端口放行。

## 第一次实机测试

1. 使用华为浏览器打开页面，并横屏使用。
2. 勾选知情说明，选择“固定文本抄写”。
3. 使用Huawei Pencil自然抄写完整句子。
4. 观察“输入、压感、倾角”是否显示为已检测。
5. 导出JSON和PNG。
6. 点击“新建会话”，再导入刚才的JSON并回放。
7. 将导出的JSON复制到 `data/mock/handwriting/device-check/`，不要提交包含真实姓名的文件。

## 通过标准

- 输入类型至少识别为 `pen`。
- JSON包含多个stroke以及连续的sequence。
- JSON重新导入后可以还原主要笔迹。
- 如果设备暴露压感，pressure不应始终为空或固定值。
- 如果浏览器没有暴露压感/倾角，必须原样记录“未检测”，不能人工补造。

## 已知限制

- 不同华为平板、Pencil和浏览器版本对Pointer Events字段的支持可能不同，必须以实际导出文件为准。
- 当前回放按采样点匀速绘制，后续会改为按原始时间间隔回放。
- 当前只做数据采集和设备验证，不输出任何心理解释。
