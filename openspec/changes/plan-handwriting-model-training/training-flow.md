# MindTrace 模型训练流程

执行路线：**数据保护与环境 → 统一轨迹与特征 → OUHD-L 自监督预训练 → EMOTHAW 监督对照 → MindTrace WHO-5 迁移 → 独立评价 → 受门控推理交付**。

这里训练的是 BiGRU 笔迹时序模型。OUHD-L 为正式预训练源；CASIA-onDo 后续取得时只增加独立补充实验。无需训练语言模型或生成式报告组件。

## 1. 保护数据，准备训练环境

- 补齐原始数据、问卷、派生数据、划分、模型和逐人结果的 Git 忽略规则，保留原始文件及受控备份。
- 创建独立 `ml/.venv`，使用 Python 3.10，安装 PyTorch 后实测 CUDA、前向计算和模型保存加载，再锁定依赖。
- 使用 RTX 4060 Laptop 8GB，先做小规模单种子运行，记录显存与吞吐量再安排正式夜间任务。

验收：环境可复现，数据不进入提交，GPU 实测结果已记录。

## 2. 先把 OUHD-L 变成可靠的模型输入

- 从 manifest 读取真实轨迹，以 writer_id 保留官方训练/验证/测试划分；先划分参与者，再切窗。
- 保留原始单位与来源。时间保留可取得的 epoch ms 和相对 ms，模型侧 dt 用秒；源中没有 epoch 时显式标缺失。
- 同刻同笔状态位置/压力取均值；同刻状态转换保留边界、dt=0、速度无效并计数；时间倒序隔离复核，不自动排序。
- 输出 `dx、dy、dt、pressure、pen_state`，同时输出测量缺失、遮盖、padding 各自的掩码和笔画边界。
- 跨设备用归一化坐标。MindTrace 浏览器压力0–1与OUHD-L 0–4095不能直接比较；MindTrace动态压力有效条件为pen且范围≥0.01。
- 提取速度、压力、停顿、轨迹形状与大小等统计特征，停顿以200/500/1000ms做敏感性分析并记录版本。

验收：轨迹与统计图可抽查，无零dt除法或标签错配，修复可追溯且原始文件不变。归一化参数只从训练集合拟合。

## 3. 小规模跑通，再冻结正式窗口

- 256点窗口仅用于调通数据加载、掩码、模型前向与反向、检查点保存恢复。
- 正式实验比较2秒时间窗，或统一频率重采样后再切窗；避免500Hz与约125Hz的原始等点数窗口代表不同时长。
- 频率、窗步长、短窗和插值规则在验证集/训练内层选择并冻结；不把长抬笔间隔插成落笔轨迹，不使用测试集选择参数。

验收：冻结输入通道、窗口和预处理版本，正式运行不沿用未经验证的原始256点跨域比较。

## 4. OUHD-L 正式自监督预训练

- 模型：2层BiGRU，单方向hidden=64，双向表示128维，dropout=0.2。
- 随机遮盖约15%的连续有效轨迹，重建dx/dy/dt/pressure；仅在被遮盖且真实有效的通道计算Huber损失。
- 起始配置：AdamW、学习率0.001、batch 32、最多50 epoch、验证损失连续7轮无改善早停；显存不足调整batch/梯度累积并记录。
- 保存最佳编码器、配置、来源、划分、环境与训练历史；冻结模型后评价独立测试集重建指标。

产物：**OUHD-L预训练笔迹编码器**。重建成功仅表示学到轨迹表征，不代表能预测WHO-5。

## 5. EMOTHAW 内部适配与授权后监督实验

本步骤的格式适配、质检和管线测试可与前述工作并行。当前镜像不发表、不再分发；正式训练与论文结果发布前取得作者实验室书面授权。

- 只读一个canonical数据根，按Directory + File Number user连接标签，处理重复、修正版、缺任务和异常轨迹。
- 原研究I-DASS-42已确认，镜像计分历史待核验；保留Excel原值，先复核冻结已有探索，不追加分析。样本内关联/回归不能替代正式预测验证，不能绕过正式训练授权门槛。
- DASS-21/42保留独立原始与换算口径；分类严重度仅依据Lovibond & Lovibond (1995)原版手册。
- 正式授权与镜像计分核验齐备后，优先连续分数回归：先建立Dummy、Ridge与人工特征Random Forest回归基线，再比较同结构BiGRU从零、冻结编码器和局部微调。三个DASS维度分别预测；分类保持关闭，不列必做。
- 使用外层5折参与者分组、内层分组选参，最终3种子，保持相同划分与可比预算。

产物：可比较的公开监督实验及候选编码器。若无法取得正式使用条件，记录跳过原因，保留 **OUHD-L → MindTrace** 直接迁移路径。

## 6. MindTrace WHO-5 基线与迁移

- 数据收集后放入 `ml/data/raw/mindtrace/`，按20人×3轮规划；60人次上限不等于60名独立参与者。
- 核验WHO_5身份、五题有效性与质量记录，主标签为rawTotal 0–25，percentageScore=rawTotal×4；不混用旧MRS-18或DASS标签。
- 同人同轮为一个监督样本，两次标准抄写聚合为主；自由书写与热身只作独立消融分支。
- 先跑Dummy、Ridge和人工特征Random Forest，再给候选编码器训练新的WHO-5回归头，比较表示与统计特征融合。
- 问卷答案、得分和派生提示不作为笔迹预测输入；标签待复核记录不参与监督。

产物：WHO-5目标域基线、迁移模型与融合对照，不沿用DASS预测头。

## 7. 独立验证与展示验收

- 主评估为LOSO：留出一名参与者的全部轮次，训练参与者内部完成选参、早停、预处理和预测区间校准。
- 最终运行3种子，报告MAE、RMSE、Spearman、逐人误差、参与者级配对bootstrap，以及个人预测区间覆盖和宽度。
- 执行去掉压力/速度/形状的消融、训练标签置乱负对照；个体内纵向变化关联单独报告。
- 最终评估前预登记误差与种子聚合口径、bootstrap和预测区间方法，不根据外层测试结果调整。

个人预测展示必须同时满足：

1. LOSO MAE较Dummy降低至少20%，且不劣于预登记Ridge/人工特征基线。
2. 参与者级配对bootstrap改善量的95%置信区间下界大于0。
3. 3种子至少2个方向一致，名义80%个人预测区间的实测覆盖率在70–90%。

任何一项未达标，预测分数为null，只展示测量与研究汇总。置信区间不能代替个人预测区间；负结果也应完整保留。

## 8. 导出模型与交付

导出权重、预处理参数、通道/特征顺序、WHO-5目标定义、模型/质量规则版本与验收状态。验证输入兼容性与质量门控，通过验收后才接入推理；不合格输入或未验收模型不返回个人预测。

模型训练截止2027年1月，整体项目截止2027年4月。按2–3个夜间时段初步安排，断点续训；目前10–20 GPU·小时总预算与12–25小时分项估算存在差异，应以冒烟吞吐量重估，并计入内层调参、区间校准、消融和重跑开销。
